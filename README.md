#✨ About

RenPy Translator is a desktop application designed to simplify the process of translating **Ren'Py visual novels**.

Instead of manually editing `.rpy` files, translators can manage dialogues through a clean and modern interface, making the localization workflow faster, safer, and more organized.

---

# 🚀 Features

## Current

- Scan Ren'Py projects
- Parse dialogue files
- Extract translatable text
- Project-based translation workflow
- Modern desktop interface
- Open-source

---

## Planned

- Dialogue editor
- Inline translation editing
- Translation progress tracking
- Export translation patches
- Multi-language support
- Auto-save project
- Search & Filter
- Theme support

# ⚡ Installation

Clone the repository

```bash
git clone https://github.com/systemzerodev/RenPy-Translator.git
```

Go into the project

```bash
cd RenPy-Translator
```

Create a virtual environment

```bash
python -m venv venv
```

Activate it

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python main.py
```
